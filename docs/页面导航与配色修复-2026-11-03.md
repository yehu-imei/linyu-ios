# 页面导航与配色修复

- 全局隐藏 SwiftUI 滚动指示条，仍保留滚动、下拉刷新。
- 组件普通导航同步消费，与水控队列分开。水控忙碌时丢弃迟到的导航，不在开启完成后返回首页。组件异步操作增加单实例处理保护；刷新完成时若已产生新的使用会话，不覆盖使用页面。
- Android `Theme.kt:89` 仅用主页背景提取色覆盖 Accent；正文仍由深浅主题控制。iOS 保留相同规则，不按整张背景图自动切换正文黑白。
- Android `FloatingPillNavBar.kt:131` 使用 `Color.luminance()` 选择强调色上的文字；iOS 原为直接对 sRGB 加权，现补齐线性转换，阈值仍为 0.5。
- 组件不再在数据完全没变时每 15 秒重载；重复点击当前页不写选择文件。切页仍读取本地快照，不联网。不能保证消除 WidgetKit 调度延迟。

验证：增加普通导航与水控分类、线性亮度边界回归。构建只证明编译及离线测试；“从组件普通入口进入后，在 App 开水”与滚动视觉仍需真机复测。本次没有操作真实热水器。
