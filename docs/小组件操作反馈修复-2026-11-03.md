# 小组件操作反馈修复

## 真机日志证据

`linyu-log-20261103-150325.txt` 中两次开阀成功、两次关阀请求受理；页面不变不能作为未执行水控的证据。日志没有旧版组件入口追踪，不能把每个请求归因到具体一次点击。关阀受理也不等于物理阀门已确认关闭。

## 本次调整

- “选用”恢复为只写入组件选中设备、切回控制页，不打开 App、不发起水控；设备名称另作详情入口。
- 前台 AppIntent 不直接投递水控，改为打开应用 URL，由应用场景统一处理。进入应用后先退出遮挡页面，再展示查询、扫描、开启或关闭进度。
- 首页的开水、恢复订单成功后明确进入目标设备使用页，包括同一设备此前被最小化的情况。
- 增加组件入口、处理开始和结束日志，不记录账户标识或随机令牌。
- 合并台账已确认的地址与 SN，兼容旧选择和消费缓存。没有对应设备消费记录时仍显示缺省值，不拿其他设备账单填充。
- 退出登录弹窗紧凑化；组件字体、间距、图标和卡片按 Android XML 对照调整。只有小型设备卡和中型多页卡。
- 切页仅读写本地快照，不请求网络，不额外刷新全部组件；增加系统日志耗时记录。WidgetKit 调度延迟不等于本地缓存耗时，不能承诺与 Android 同步重绘一样即时。

## 验证边界

纯逻辑回归覆盖别名匹配、防串账、身份和订单校验。Actions 编译、模拟器预览不等于真机开关水测试。
真机需测试：后台/冷启动组件开水可见进度并进入使用页；软件内开水可进入使用页；关闭返回空闲；选用不打开 App；不同设备不串账。测试前确认现场阀门状态，勿在页面无反馈时反复开启。
