# 3.1.1（19）发布与验收

日期：2026-11-06。Android、iOS 主应用与 Widget 扩展统一版本；不合入 Android 洗衣机 / 项目切换 PR #12

## 蓝牙结算修复

两端均把“上传被接受”和“设备记录已清除”分开处理。上传失败仍按原有恢复路径处理；服务器接受后保留金额，清理失败不再上报作废

写回之后查询设备，只有空闲状态 0 才确认清理成功。写回应答成功但设备仍为 3/6、查询超时或异常，都不会提示已清理。应答丢失但查询已空闲则可以确认，不在确认步骤重复上传。iOS 还核对设备身份与当前登录会话

开阀前补结算未确认清理时提示“账单已结清，设备清理未确认，请靠近后重试”，不创建新订单。正常关阀已上传成功时继续显示实际消费，不把清理状态误当水仍在流

## 验证范围

- 发布门槛：Android 单元测试、Lint、Release 与签名校验；iOS Swift 回归、Archive、小组件离线截图、主应用 / 扩展版本与 App Group 校验
- 两仓库 IPA 复用同一文件，发布前核对 SHA-256；包内简版日志与仓库文档一致
- 不使用真实账户或水表做自动化开关、扣款测试；本次没有完成新候选包的真实水控验收
- 自动测试不代表所有学校兼容；请确认关水结果后离开设备

## 真机验收清单

1. 覆盖安装保留账户；两端版本 3.1.1，构建号 19
2. 云端 / 蓝牙开关水，结算金额与官方账单核对
3. 蓝牙遗留记录正常清理后可以重新开阀；异常时不误报清理成功
4. 从小组件冷启动和后台恢复进入，操作正确设备；再手动开水不闪回首页
5. 结束后小组件状态、上次消费和账单更新，旧快照不执行另一笔订单
6. 使用码额度、账户展开按钮、背景、扫码权限、日志与更新文档缓存回归
